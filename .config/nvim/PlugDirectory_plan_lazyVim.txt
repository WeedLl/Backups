Как это работает

Поток загрузки:

init.lua → загружает core/options, core/autocmds, core/keymaps, plugins/init
plugins/init.lua → бутстрапит lazy.nvim, вызывает require("lazy").setup("plugins")
lazy.nvim автоматически читает все .lua-файлы из lua/plugins/ (кроме init.lua, который уже отработал как бутстрап)
Каждый файл в lua/plugins/ возвращает таблицу спецификаций плагинов
Когда плагин загружается (сразу или лениво), lazy.nvim вызывает его config-функцию
config-функция делает require("configs.xxx") — загружает файл из lua/configs/
Почему config, а не opts:

opts — сокращение для function() require("plugin").setup(opts) end. Удобно для простых плагинов, где нужно передать только таблицу с настройками. Но в ваших плагинах (gruvbox, lsp, neo-tree) после setup() идут дополнительные действия (colorscheme, маппинги, highlight) — поэтому config с отдельным файлом гибче.

Почему init у vimtex, а не config:

vimtex — vimscript-плагин. Он читает vim.g.vimtex_* переменные в момент загрузки, а не через setup(). Поэтому переменные нужно выставить до того, как плагин загрузится. Поле init выполняется до загрузки, а config — после. Для vimscript-плагинов это ключевое различие.

Защита pcall:

В каждом файле из lua/configs/ первая строка — pcall(require, "plugin"). Если плагин ещё не установлен (первый запуск), require вернёт ошибку, а pcall её перехватит. Neovim не упадёт, а просто пропустит конфиг.

Ленивая загрузка:

Обратите внимание на поля event, cmd, ft, keys в спецификациях — они определяют, когда плагин загрузится:

Плагин	Триггер	Почему
gruvbox	сразу (lazy = false)	нужна до отрисовки UI
lualine	VeryLazy	после старта, не блокирует UI
treesitter	BufReadPost	при открытии файла
neo-tree	cmd, keys	при вызове :Neotree или <C-n>
lspconfig	BufReadPre	при открытии файла, до чтения
blink.cmp	InsertEnter	при входе в insert-режим
LuaSnip	InsertEnter	там же
vimtex	сразу (lazy = false)	документация вимтекса требует
render-markdown	ft = markdown	только для markdown-файлов
Это даёт быстрый старт — тяжелые плагины грузятся только когда реально нужны.

Создайте все файлы и запустите nvim — lazy.nvim скачает и установит всё автоматически.
