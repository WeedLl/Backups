Рекомендуемая структура:

text
~/.config/nvim/
├── init.lua              # точка входа
├── lua/
│   ├── options.lua       # настройки редактора
│   ├── autocmds.lua      # автокоманды
│   ├── keymaps.lua       # горячие клавиши
│   └── plugins/
│       ├── init.lua      # lazy.nvim bootstrap + список плагинов
│       ├── lsp.lua       # LSP-конфигурация
│       ├── cmp.lua       # автодополнение
│       └── ...            # по одному файлу на крупный плагин

Или расширенный вариант:
~/.config/nvim/
├── init.lua                  # минимальный файл: подключает модули и запускает менеджер плагинов
├── lua/
│   ├── core/                 # базовые опции, настройки терминала, termguicolors, undofile и т.д.
│   │   ├── options.lua
│   │   ├── keymaps.lua        # твои маппинги (в т.ч. из .vimrc), leader-клавиши
│   │   └── autocmds.lua       # автокоманды (BufEnter, FileType и т.п.)
│   ├── plugins/              # описания плагинов и их setup() (packer/lazy)
│   │   ├── packer.lua         # список плагинов для packer
│   │   └── lazy.lua           # список плагинов для lazy (альтернатива)
│   └── config/               # конфиги конкретных плагинов (gitsigns, lspconfig, nvim-cmp и т.д.)
│       ├── gitsigns.lua
│       ├── lsp.lua
│       └── cmp.lua
└── after/                    # Vimscript‑файлы, которые выполняются ПОСЛЕ всех плагинов
    ├── plugin/
    │   └── custom-mappings.vim   # маппинги, которые должны применяться в конце
    └── ftplugin/
        ├── python.vim            # специфичные настройки для Python (твоя задача с комментарием)
        └── markdown.vim
